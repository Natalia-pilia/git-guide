## ნაბიჯი 1 - Tailwind-თან მუშაობა
ახლა შექმენი ფაილი `index.html`, დააკავშირე Tailwind-თან და მიყევი ინსტრუქციას:
მოიძიე 3 გემრიელი შაურმის სურათი და ჩასვი ისინი (რეკომენდირებულია ცალკე ფოლდერის შექმნა ფოტოებისთვის, მაგრამ აუცილებელი არ არის, უბრალოდ ასე უფრო მოსახერხებელი იქნება).
ახლა, ფლექსით გაცენტრე ეს სურათები და ჰოვერის გამოყენებით გააკეთე ისე, რომ როდესაც კურსორი შაურმასთან მივა, ის "ახტება" და გააკეთებს სალტოს ჰაერში.
გაკეთების პროცესში Tailwind-საც გაიხსენებ გითთან ერთად.
როდესაც დაასრულებ, არ დაგავიწყდეს კომიტის გაკეთება. მაგრამ `git push` ჯერ არ გააკეთო, რადგან რაღაცეები გვაქვს კიდევ დასამატებელი.
